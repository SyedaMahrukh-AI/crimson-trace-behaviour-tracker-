# Crimson Trace | Website Interaction Visualizer

A browser-based project for exploring how users interact with a website through mouse movement, clicks, and other on-page activity.

Crimson Trace presents interaction data through a visual dashboard, making it easier to observe where users click and how they move around a webpage.

## Overview

The project was developed to experiment with client-side event tracking and visual representations of website activity. It combines a dashboard interface with JavaScript-based interaction tracking.

## What It Does

* **Click Mapping** — Displays the locations where clicks occur on the page.
* **Interaction Scatter Plot** — Shows individual click positions visually.
* **Mouse Tracking** — Records mouse movement across the tracked area.
* **Activity Statistics** — Presents collected interaction information.
* **Event History** — Keeps a record of captured events.
* **Visibility Monitoring** — Tracks supported element visibility events.
* **Data Export** — Allows collected data to be exported as JSON.

## Getting Started

No separate installation is needed for the basic version.

1. Clone or download this repository.
2. Locate the main HTML file.
3. Open it in a modern web browser.
4. Start a tracking session and interact with the page.
5. Explore the available visualizations and activity records.

## Project Focus

This project explores browser events, mouse coordinates, click distribution, and the presentation of interaction data in a visual interface.
